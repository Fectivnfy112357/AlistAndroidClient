# Alist 安卓客户端 · 产品与界面说明

> 用途：本文档面向界面/交互/产品，供转换为原型页面使用。不含技术实现细节。

## 一、产品定位

一款连接 **Alist 私有网盘服务** 的安卓客户端。用户通过「服务器地址 + 账号密码」登录自己的 Alist 服务器，在手机上浏览、管理、传输云端文件，并对服务器（存储源、站点设置）进行管理员级别的维护。

用户登录自己的 Alist 服务器后，即可浏览文件、上传/下载、分享、查看传输进度，也能在客户端内管理存储源（如阿里云盘、夸克、百度网盘等挂载）并调整站点设置——所有能力对登录用户一致开放。

## 二、整体信息架构

```
登录页（独立，无底部导航）
        │
        ▼
主框架（底部 4 个 Tab）
 ├─ 首页        仪表盘：服务器概览 + 存储入口
 ├─ 文件        文件浏览器：目录树、搜索、批量操作
 ├─ 传输        上传/下载任务列表（进行中 / 已完成 / 失败）
 └─ 设置        主题、存储管理、快速设置、维护、退出登录
        │
        ▼（由底部 Tab 或卡片进入的二级页）
   ├─ 文件预览页（图片 / 文本 / 音频 / 其他）
   ├─ 移动/复制选择页（选目标目录）
   ├─ 存储编辑页（单个存储源的参数配置）
   └─ 完整设置页（全部站点设置项，分组表单）
```

全局规范：
- **顶部应用栏**：标题 + 副标题（常显示当前路径或在线/离线状态），部分页含「返回」「上传」「刷新」等图标按钮。
- **底部导航栏**：仅首页/文件/传输/设置 4 个页显示，其余二级页隐藏并显示返回按钮。
- **在线/离线状态**：顶栏副标题与多处横幅提示。离线时传输暂停、部分操作不可用。
- **加载态 / 错误态 / 空态**：列表与卡片统一支持，错误态提供「重试」。

## 三、页面逐页说明

### 1. 登录页
**目的**：连接并登录 Alist 服务器。

布局（居中卡片式）：
- 锁形图标 + 标题「登录 Alist」
- 输入框「服务器地址」（如 `http://127.0.0.1:5244`）
- 输入框「用户名」
- 输入框「密码」（密文）
- 主按钮「登录 Alist」（加载中显示进度）
- 错误时顶部红色横幅；使用 HTTP 明文时黄色警告「账号密码可能被窃听」

用户操作：填写三项 → 点登录 → 成功进入主框架。

### 2. 首页（仪表盘）
**目的**：一眼掌握服务器状态，快速进入存储。

布局（可下拉刷新，分区卡片）：
- **服务器卡片（Hero）**：显示站点名称（如「Alist」）+ 副标题「当前服务器」。
- **指标行（3 个小卡）**：用户数、角色数、在线人数。加载失败显示「重试」。
- **后台任务卡**：显示「进行中 N」，并以标签展示各任务类型数量（上传 / 复制 / 离线下载 / 离线转存 / 对象存储迁移 / 解压 / 解压上传）。无权限时提示「需要管理员权限」。
- **存储区**：列出已挂载存储源，点击进入该存储的文件浏览。

用户操作：下拉刷新；点击存储进入文件页；某区失败点「重试」。

### 3. 文件页
**目的**：浏览、搜索、管理云端文件与目录。

布局：
- 顶部：标题「文件」+ 副标题为当前路径；右侧「上传」「刷新」图标。
- 搜索框（实时按名称过滤）。
- 离线时黄色横幅「当前离线，部分操作不可用」；出错时红色横幅可「重试」。
- 文件列表：图标区分类型（文件夹/文件），显示名称、大小、修改时间。
- 多选模式时底部出现操作条：已选数量、全选、删除、下载、取消选择。

用户操作（单文件常用操作， via 行内菜单）：
- 打开预览、进入子目录、分享（系统分享直链）、复制直链、下载。
- 多选后：批量删除（弹确认框「不可恢复」）、批量下载。
- 顶部上传：从本机选择文件加入上传队列；刷新重载当前目录。

（新建文件夹、重命名、复制、移动等维护操作在此页或其菜单触发，复制/移动会进入「选择目标目录」页。）

### 4. 传输页
**目的**：查看和管理上传/下载任务。

布局：
- 顶部：标题「传输」+ 副标题为汇总（如「3 进行中 · 1 失败」）。
- 分段选择器切换标签：**全部 / 上传 / 下载 / 失败**（标签文案以实际为准）。
- 任务列表行：文件名、进度、状态；支持「取消 / 重试 / 删除」。
- 离线时黄色横幅「传输操作已暂停」。
- 空态有引导文案（如「对应类型的传输任务会显示在这里」）。

用户操作：切换标签、下拉刷新、取消/重试/删除任务。

### 5. 设置页
**目的**：个性化与服务器/账号管理。

分区：
- **主题**：浅色 / 深色 / 跟随系统（单选）。
- **存储**：列出存储源（显示备注或挂载路径、驱动类型，禁用态标「已禁用」），点击进入存储编辑页。
- **快速设置**：少量常用站点设置项（如站点公告），点击弹对话框编辑并保存。
- **维护**：
  - 「清理临时预览文件」：释放本机预览缓存。
  - 「完整设置」：进入全部站点设置表单页。
- 底部「退出登录」按钮（描边样式）。

用户操作：切换主题、进存储编辑、改快速设置、清理缓存、进完整设置、退出登录。

### 6. 文件预览页
**目的**：查看单文件内容。

布局：
- 顶部：标题「文件预览」+ 副标题为文件名；操作图标「下载」「用其他应用打开」。
- 内容区按类型渲染：
  - 图片：图片预览。
  - 文本：文本内容。
  - 音频：播放器。
  - 其他/不支持：兜底提示（可下载或在外部打开）。

用户操作：下载、调用外部应用打开、返回。

### 7. 移动/复制选择页
**目的**：为「复制 / 移动」操作选择目标目录。

布局：目录浏览列表（类似文件页的精简版），选定目标后确认。

用户操作：浏览并选择目标目录 → 确认执行复制/移动。

### 8. 存储编辑页
**目的**：配置单个存储源。

布局（可滚动表单）：
- 顶部「编辑存储」+ 返回。
- 信息卡：挂载路径、驱动（如 Quark / BaiduNetdisk / 本地等）。
- 「驱动参数」卡：按驱动动态生成的表单字段（账号、令牌、根目录路径等）。
  - 对 **夸克 / 百度网盘** 等驱动，cookie 字段旁有「获取」按钮，弹出 Web 视图引导抓取登录 Cookie。
- 「启用存储」开关。
- 错误提示横幅；底部「保存」按钮（保存中显示进度，成功自动返回）。

用户操作：填参数、按需抓取 Cookie、切换启用、保存。

### 9. 完整设置页
**目的**：编辑服务器全部站点设置。

布局（可滚动，按分组卡片）：
- 顶部「完整设置」+ 返回。
- 多个分组卡，每组含若干设置项（文本/开关/选择等），按服务端配置动态渲染。
- 错误提示；底部「保存」按钮（保存成功自动返回）。

用户操作：逐项修改、保存。

## 四、关键用户流程

1. **首次使用**：登录页填服务器+账号密码 → 登录 → 首页。
2. **找文件**：首页点存储 / 文件 Tab 逐层进入目录 → 搜索过滤 → 点开预览。
3. **传文件**：文件页点上传选本机文件（入队）→ 传输页看进度 → 完成后在目标目录出现。
4. **分享**：文件页分享/复制直链 → 发给他人。
5. **整理**：多选删除/下载；或复制/移动到其他目录（经选择页）。
6. **管理服务器**：设置 → 存储编辑参数/Cookie → 启用；或完整设置调站点项。
7. **个性化**：设置 → 主题浅/深/跟随系统。
8. **换设备/退出**：设置 → 退出登录 → 回到登录页。

## 五、界面风格提示

- Material 3 风格，圆角卡片、分区清晰。
- 支持浅色/深色/跟随系统三套主题。
- 状态用顶部横幅（红=错误，黄=警告/离线）而非弹窗打断。
- 强调「下拉刷新」「行内菜单」「底部操作条」等移动端习惯交互。
- 列表统一具备加载中、错误（可重试）、空态三种状态。
